# KonneKt M5: Standby Modes & Mac Media Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make media and sound work when the PC is a Mac (including browser audio), and replace standby with four modes: Clock with four swipeable faces, Development, Multimedia, and Media + Apps. Standby opens on its own when the phone is docked.

**Architecture:**
- **Desktop (`shared/jvmMain`):**
  - Gains a MediaRemote-adapter media session behind a fallback wrapper.
  - Logs failures in `ControlSession` instead of hiding them.
  - Handles a new `ActivateAppCommand` (focus the app if it is running, otherwise launch it) through `AppCatalogService` and `WindowActuator`.
- **Android:**
  - Standby moves from `ConnectedShell` to the app root.
  - A new `StandbyViewModel` (MVVM with a `@Stable` actions interface, as the `android-skills:android-dev` convention describes) owns the mode, using the pure `StandbyModePolicy`.
  - Pager state stays in the UI, because framework state should not be hoisted into the ViewModel (`android-skills:compose`). Pages and the ViewModel are kept in sync in both directions without feedback loops.

**Tech Stack:** Kotlin 2.4, Compose Multiplatform Material3 1.11 (expressive), kotlinx.serialization, coroutines/Flow, DataStore Preferences, JNA (Win32), JXA/Perl on macOS, `kotlin.test` + `kotlinx-coroutines-test`, Compose preview screenshot tests.

## Review Focus

1. **Docking with no paired PC.** `ConnectionService` (which hosts `AutoStandbyManager`) only runs once a PC is paired. A phone that has never paired gets no auto-clock. That's expected; don't "fix" it by starting the service unconditionally.
2. **Unplugging while in a PC mode.** Standby must exit (`isAutoStandby` becomes false), as it does today. A PC disconnecting must **not** exit standby: it switches to Clock. Task 9 tests the disconnect rule.
3. **Pager feedback loops.** When the ViewModel changes the mode on its own (a PC connects), the pager animation must not report that page back as a user choice, or `userPicked` flips to true and later auto-switches stop. Task 13 guards this, and Task 9 tests the policy.
4. **Volume held at 0 % or 100 %.** The repeater keeps firing, but the value must clamp, the haptic must change to the "limit" type, and release must send exactly one `final = true` value. Task 10 tests the timing, Task 12 tests the clamp, and Task 11 handles the haptic.
5. **Older desktop or older phone.** An old desktop has no `canActivate` or `shortcutId`, so the phone must send `LaunchAppCommand` and show no running dots. An old phone ignores the new fields. Task 6 tests the decode of payloads with fields missing.

```kotlin
package com.saubh.deskbuddy.server

import java.nio.file.Files
import java.nio.file.Path
import java.nio.file.StandardCopyOption
import java.nio.file.StandardOpenOption
import java.time.Instant

/** Append-only log with one rotated backup. Never throws: logging must not break the command it reports on. */
class ServerLogFile(private val file: Path, private val maxBytes: Long) {
    @Synchronized
    fun write(line: String) {
        runCatching {
            Files.createDirectories(file.parent)
            if (Files.exists(file) && Files.size(file) + line.length > maxBytes) {
                Files.move(file, file.resolveSibling("${file.fileName}.1"), StandardCopyOption.REPLACE_EXISTING)
            }
            Files.writeString(file, "${Instant.now()} $line\n", StandardOpenOption.CREATE, StandardOpenOption.APPEND)
        }
    }
}

        System.err.println(line)
        file.write(line)
```

```kotlin
package com.saubh.deskbuddy.server.media

import com.saubh.deskbuddy.protocol.NowPlayingCommand
import com.saubh.deskbuddy.protocol.PlaybackStatus
import kotlinx.serialization.json.Json
import kotlinx.serialization.json.JsonElement
import kotlinx.serialization.json.JsonNull
import kotlinx.serialization.json.JsonObject
import kotlinx.serialization.json.booleanOrNull
import kotlinx.serialization.json.contentOrNull
import kotlinx.serialization.json.jsonPrimitive
import kotlinx.serialization.json.longOrNull

/**
 * Folds `mediaremote-adapter stream --micros` lines into samples. Diff lines merge onto the last full
 * payload (a null value removes the key), so one instance must see every line of one process, in order.
 */
class MediaRemoteStream(private val clockMs: () -> Long = System::currentTimeMillis) {
    private var payload: Map<String, JsonElement> = emptyMap()

    fun accept(line: String): MediaRemoteSample? {
        val obj = runCatching { Json.parseToJsonElement(line) as? JsonObject }.getOrNull() ?: return null
        if (obj.string("type") != "data") return null
        val incoming = obj["payload"] as? JsonObject
        val diff = obj["diff"]?.let { runCatching { it.jsonPrimitive.booleanOrNull }.getOrNull() } ?: false
        payload = when {
            incoming == null -> emptyMap()
            diff -> (payload + incoming).filterValues { it !is JsonNull }
            else -> incoming.filterValues { it !is JsonNull }
        }
        return sample()
    }

    private fun sample(): MediaRemoteSample {
        val title = payload.string("title").orEmpty()
        if (title.isBlank()) return MediaRemoteSample(NowPlayingCommand.NONE, "", null, null)
        val bundle = payload.string("bundleIdentifier").orEmpty()
        val artist = payload.string("artist").orEmpty()
        val album = payload.string("album").orEmpty()
        val playing = payload["playing"]?.let { runCatching { it.jsonPrimitive.booleanOrNull }.getOrNull() } == true
        val durationMs = (payload.long("durationMicros") ?: 0L) / 1_000
        val elapsedMs = (payload.long("elapsedTimeMicros") ?: 0L) / 1_000
        val stampMs = (payload.long("timestampEpochMicros") ?: 0L) / 1_000
        val drift = if (playing && stampMs > 0) (clockMs() - stampMs).coerceAtLeast(0) else 0L
        val position = (elapsedMs + drift).let { if (durationMs > 0) it.coerceAtMost(durationMs) else it }
        val artwork = payload.string("artworkData")?.takeIf { it.length / 4 * 3 <= MacArtworkFetcher.MAX_BYTES }
        return MediaRemoteSample(
            state = NowPlayingCommand(
                title = title,
                artist = artist.ifBlank { null },
                album = album.ifBlank { null },
                appName = bundle.takeIf { it.isNotBlank() }?.let(MediaRemoteApps::displayName),
                status = if (playing) PlaybackStatus.PLAYING else PlaybackStatus.PAUSED,
                positionMs = position,
                durationMs = durationMs,
                canSeek = durationMs > 0,
            ),
            trackKey = "$bundle|$title|$artist|$album",
            artworkMimeType = artwork?.let { payload.string("artworkMimeType") },
            artworkBase64 = artwork?.takeIf { payload.string("artworkMimeType") != null },
        )
    }

    private fun Map<String, JsonElement>.string(key: String): String? =
        this[key]?.let { runCatching { it.jsonPrimitive.contentOrNull }.getOrNull() }

    private fun Map<String, JsonElement>.long(key: String): Long? =
        this[key]?.let { runCatching { it.jsonPrimitive.longOrNull }.getOrNull() }
}
```

`MediaRemoteAdapter.kt`:
```kotlin
package com.saubh.deskbuddy.server.media

import java.nio.file.Files
import java.nio.file.Path
import java.util.concurrent.TimeUnit

/**
 * The bundled `mediaremote-adapter` (BSD-3, github.com/ungive/mediaremote-adapter). It runs under the
 * system perl, which macOS 15.4+ still lets use MediaRemote, so it sees every app's now playing (browsers too).
 */
class MediaRemoteAdapter(
    private val script: Path,
    private val framework: Path,
    private val run: (List<String>) -> Int = ::runQuiet,
) {
    fun command(vararg args: String): List<String> = listOf(PERL, script.toString(), framework.toString()) + args

    fun startStream(): Process =
        ProcessBuilder(command("stream", "--micros", "--debounce=100")).redirectError(ProcessBuilder.Redirect.DISCARD).start()

    fun isWorking(): Boolean = run(command("test")) == 0

    fun send(id: Int): Boolean = run(command("send", id.toString())) == 0

    fun seek(positionMs: Long): Boolean = run(command("seek", (positionMs.coerceAtLeast(0) * 1_000).toString())) == 0

    companion object {
        const val SEND_TOGGLE = 2
        const val SEND_NEXT = 4
        const val SEND_PREVIOUS = 5
        private const val PERL = "/usr/bin/perl"
        private const val TIMEOUT_MS = 3_000L

        /** Compose Desktop sets `compose.application.resources.dir` for both the packaged app and `./gradlew run`. */
        fun locate(resourcesDir: String? = System.getProperty("compose.application.resources.dir")): MediaRemoteAdapter? {
            val dir = resourcesDir?.let(Path::of) ?: return null
            val script = dir.resolve("mediaremote-adapter.pl")
            val framework = dir.resolve("MediaRemoteAdapter.framework")
            return if (Files.isRegularFile(script) && Files.isDirectory(framework)) MediaRemoteAdapter(script, framework) else null
        }

        private fun runQuiet(command: List<String>): Int = runCatching {
            val process = ProcessBuilder(command)
                .redirectOutput(ProcessBuilder.Redirect.DISCARD)
                .redirectError(ProcessBuilder.Redirect.DISCARD)
                .start()
            if (!process.waitFor(TIMEOUT_MS, TimeUnit.MILLISECONDS)) {
                process.destroyForcibly()
                -1
            } else {
                process.exitValue()
            }
        }.getOrDefault(-1)
    }
}
```

`MacMediaRemoteSessionActuator.kt`:
```kotlin
package com.saubh.deskbuddy.server.media

import com.saubh.deskbuddy.protocol.NowPlayingCommand
import com.saubh.deskbuddy.server.Artwork
import com.saubh.deskbuddy.server.MediaSessionActuator
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import java.nio.charset.StandardCharsets
import kotlin.concurrent.thread

/** System-wide now playing on macOS through [MediaRemoteAdapter]; restarts the stream with backoff (1 s, 2 s, 4 s). */
class MacMediaRemoteSessionActuator(
    private val adapter: MediaRemoteAdapter,
    private val clock: () -> Long = System::currentTimeMillis,
) : MediaSessionActuator {

    private companion object {
        const val MAX_RESTARTS = 3
    }

    private val _state = MutableStateFlow(NowPlayingCommand.NONE)
    override val state: StateFlow<NowPlayingCommand> = _state
    private val _artwork = MutableStateFlow<Artwork?>(null)
    override val artwork: StateFlow<Artwork?> = _artwork
    private val _available = MutableStateFlow(false)
    override val available: StateFlow<Boolean> = _available

    private val filter = NowPlayingFilter()
    private val lock = Any()
    private var process: Process? = null
    private var restarts = 0
    @Volatile private var stopped = false
    /** Track whose cover is in [_artwork]; null when the current track has none yet. */
    @Volatile private var artworkTrackKey: String? = null

    override fun start() {
        stopped = false
        restarts = 0
        launchProcess()
    }

    override fun stop() {
        stopped = true
        synchronized(lock) {
            process?.destroy()
            process = null
        }
        _available.value = false
    }

    override fun refresh() {
        val alive = synchronized(lock) { process?.isAlive == true }
        if (alive) {
            filter.reset()
            _state.value = _state.value.copy()
        } else {
            restarts = 0
            launchProcess()
        }
    }

    override fun seek(positionMs: Long): Boolean = _state.value.canSeek && adapter.seek(positionMs)

    private fun launchProcess() {
        if (stopped) return
        val started = runCatching { adapter.startStream() }.getOrNull()
        if (started == null) {
            _available.value = false
            return
        }
        synchronized(lock) { process = started }
        thread(isDaemon = true, name = "konnekt-mediaremote") { readLoop(started) }
    }

    private fun readLoop(p: Process) {
        val stream = MediaRemoteStream(clock)
        runCatching {
            p.inputStream.bufferedReader(StandardCharsets.UTF_8).useLines { lines ->
                lines.forEach { line -> stream.accept(line)?.let(::handle) }
            }
        }
        onExit(p)
    }

    private fun handle(sample: MediaRemoteSample) {
        _available.value = true
        restarts = 0
        if (sample.trackKey != artworkTrackKey) artworkTrackKey = null
        val art = sample.artworkBase64
        val mime = sample.artworkMimeType
        if (art != null && mime != null && artworkTrackKey == null && sample.trackKey.isNotEmpty()) {
            // Cover before the state that names it, as the Windows helper does.
            _artwork.value = Artwork(MacNowPlayingSample.artworkId(sample.trackKey), mime, art)
            artworkTrackKey = sample.trackKey
        }
        val artworkId = if (artworkTrackKey == sample.trackKey) MacNowPlayingSample.artworkId(sample.trackKey) else null
        val next = sample.state.copy(artworkId = artworkId)
        if (filter.shouldPublish(next, clock())) _state.value = next
    }

    private fun onExit(p: Process) {
        synchronized(lock) { if (process === p) process = null }
        _available.value = false
        _state.value = NowPlayingCommand.NONE
        filter.reset()
        artworkTrackKey = null
        if (stopped || restarts >= MAX_RESTARTS) return
        Thread.sleep(1_000L shl restarts)
        restarts++
        launchProcess()
    }
}
```

`FallbackMediaSessionActuator.kt`:
```kotlin
package com.saubh.deskbuddy.server.media

import com.saubh.deskbuddy.protocol.NowPlayingCommand
import com.saubh.deskbuddy.server.Artwork
import com.saubh.deskbuddy.server.MediaSessionActuator
import kotlinx.coroutines.CoroutineScope
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.Job
import kotlinx.coroutines.SupervisorJob
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.launch

/**
 * Picks the session backend at [start] (probing the primary spawns a process, so it never runs on
 * construction) and mirrors its flows, which consumers may already be collecting.
 */
class FallbackMediaSessionActuator(
    private val choosePrimary: () -> MediaSessionActuator?,
    private val fallback: () -> MediaSessionActuator,
    private val scope: CoroutineScope = CoroutineScope(SupervisorJob() + Dispatchers.IO),
) : MediaSessionActuator {

    private val _state = MutableStateFlow(NowPlayingCommand.NONE)
    override val state: StateFlow<NowPlayingCommand> = _state
    private val _artwork = MutableStateFlow<Artwork?>(null)
    override val artwork: StateFlow<Artwork?> = _artwork
    private val _available = MutableStateFlow(false)
    override val available: StateFlow<Boolean> = _available

    @Volatile private var active: MediaSessionActuator? = null
    private var mirror: Job? = null

    override fun start() {
        mirror?.cancel()
        mirror = scope.launch {
            val chosen = active ?: (runCatching { choosePrimary() }.getOrNull() ?: fallback()).also { active = it }
            chosen.start()
            launch { chosen.state.collect { _state.value = it } }
            launch { chosen.artwork.collect { _artwork.value = it } }
            launch { chosen.available.collect { _available.value = it } }
        }
    }

    override fun stop() {
        mirror?.cancel()
        active?.stop()
        _available.value = false
    }

    override fun refresh() {
        active?.refresh()
    }

    override fun seek(positionMs: Long): Boolean = active?.seek(positionMs) ?: false
}
```

```kotlin
package com.saubh.deskbuddy.server.openapps

import java.util.concurrent.ConcurrentHashMap
import java.util.concurrent.TimeUnit

/**
 * Catalog id → the lower-cased exe a running window reports, so pinned `.lnk` shortcuts can be matched
 * to open windows. Start-menu (UWP) ids have no exe and stay unmatched; they launch instead.
 */
class ShortcutTargets(private val resolveLnk: (String) -> String? = ::lnkTarget) {
    private val cache = ConcurrentHashMap<String, String>()
    private val misses = ConcurrentHashMap.newKeySet<String>()

    fun target(appId: String): String? = when {
        appId.endsWith(".exe", ignoreCase = true) -> appId.lowercase()
        !appId.endsWith(".lnk", ignoreCase = true) || appId in misses -> null
        else -> cache[appId] ?: resolveLnk(appId)?.takeIf { it.isNotBlank() }?.lowercase()?.also { cache[appId] = it }
            ?: null.also { misses += appId }
    }

    private companion object {
        /** The path travels in an environment variable, never in the script text. */
        fun lnkTarget(path: String): String? = runCatching {
            val process = ProcessBuilder(
                "powershell", "-NoProfile", "-NonInteractive", "-Command",
                "(New-Object -ComObject WScript.Shell).CreateShortcut(\$env:KONNEKT_LNK).TargetPath",
            ).apply { environment()["KONNEKT_LNK"] = path }.redirectErrorStream(true).start()
            if (!process.waitFor(5, TimeUnit.SECONDS)) {
                process.destroyForcibly()
                return null
            }
            process.inputStream.bufferedReader().readText().trim().takeIf { it.endsWith(".exe", ignoreCase = true) }
        }.getOrNull()
    }
}
```

```kotlin
import java.util.Calendar

/** Wall-clock time for the faces. Calendar, not java.time: minSdk 24 has no desugaring here. */
data class ClockTime(val hour: Int, val minute: Int, val second: Int) {
    val isPm: Boolean get() = hour >= 12

    fun digits(is24h: Boolean): String {
        val h = if (is24h) hour else (hour % 12).let { if (it == 0) 12 else it }
        return "%02d%02d".format(h, minute)
    }

        fun now(calendar: Calendar = Calendar.getInstance()): ClockTime =
            ClockTime(calendar.get(Calendar.HOUR_OF_DAY), calendar.get(Calendar.MINUTE), calendar.get(Calendar.SECOND))
    }
}

    fun minute(time: ClockTime): Float = (time.minute + time.second / 60f) * 6f
```

```kotlin
import androidx.compose.ui.semantics.role

import kotlinx.coroutines.delay
import kotlinx.coroutines.isActive
import kotlinx.coroutines.launch

/**
 * One step on press-down, then repeats per [RepeatSchedule] while held; [onRelease] once on lift or cancel.
 * Accessibility services get a plain click (one step + release).
 */
@Composable
fun Modifier.repeatingPress(
    interaction: MutableInteractionSource,
    onStep: () -> Unit,
    onRelease: () -> Unit,
): Modifier {
    val step by rememberUpdatedState(onStep)
    val release by rememberUpdatedState(onRelease)
    return semantics {
        role = Role.Button
        onClick { step(); release(); true }
    }.pointerInput(interaction) {
        coroutineScope {
            awaitEachGesture {
                val down = awaitFirstDown()
                val press = PressInteraction.Press(down.position)
                interaction.tryEmit(press)
                step()
                val heldFrom = System.currentTimeMillis()
                val repeater = launch {
                    var repeats = 0
                    while (isActive) {
                        delay(RepeatSchedule.nextDelay(repeats, System.currentTimeMillis() - heldFrom))
                        step()
                        repeats++
                    }
                }
                val up = waitForUpOrCancellation()
                repeater.cancel()
                interaction.tryEmit(if (up != null) PressInteraction.Release(press) else PressInteraction.Cancel(press))
                release()
            }
        }
    }
}
```

```kotlin
import kotlinx.coroutines.flow.Flow
import kotlinx.coroutines.flow.catch
import kotlinx.coroutines.flow.map
import java.io.IOException

private val Context.standbyStore by preferencesDataStore(name = "standby_prefs")

/** The clock face last swiped to. A read failure falls back to the default face rather than breaking standby. */
class StandbyPrefs(private val context: Context) : ClockFaceStore {
    private val faceKey = stringPreferencesKey("clock_face")

    override val face: Flow<ClockFace> = context.standbyStore.data
        .catch { e -> if (e is IOException) emit(emptyPreferences()) else throw e }
        .map { ClockFace.fromName(it[faceKey]) }

    override suspend fun save(face: ClockFace) {
        context.standbyStore.edit { it[faceKey] = face.name }
    }
}
```

```kotlin
class StandbyViewModel(
    private val connection: StateFlow<ConnectionUiState>,
    savedDesktops: StateFlow<List<SavedDesktop>>,
    private val media: MediaController,
    apps: StateFlow<AppsUiState>,
    private val activateApp: (String) -> Unit,
    private val running: RunningAppsController,
    private val power: PowerController,
    private val faces: ClockFaceStore,

    private data class Header(val modeState: StandbyModeState, val entered: Boolean, val face: ClockFace, val link: Link)

    private val modeState = MutableStateFlow(StandbyModeState())
    private val entered = MutableStateFlow(false)

    private val link = combine(connection, savedDesktops) { state, saved ->
        Link(
            connected = state is ConnectionUiState.Connected,
            pcName = (state as? ConnectionUiState.Connected)?.desktopName ?: saved.maxByOrNull { it.lastUsedAt }?.name.orEmpty(),
            reconnectAttempt = (state as? ConnectionUiState.Reconnecting)?.attempt,
        )
    }

    val uiState: StateFlow<StandbyUiState> =
        combine(

            media.state,
            apps,
            running.state,

            StandbyUiState(

                mode = header.modeState.mode,
                clockFace = header.face,
                connected = header.link.connected,
                pcName = header.link.pcName,
                reconnectAttempt = header.link.reconnectAttempt,
                media = mediaState,
                shortcuts = appsState.shortcuts,
                shortcutIcons = appsState.icons,
                runningShortcutIds = runningState.apps.mapNotNull { it.shortcutId }.toSet(),
            )
        }.stateIn(viewModelScope, SharingStarted.WhileSubscribed(5_000), StandbyUiState())

        viewModelScope.launch {

                modeState.update { StandbyModePolicy.onConnectionChanged(it, connected) }
```

```kotlin
@Composable
fun StandbyScreen(state: StandbyUiState, actions: StandbyActions, onExit: () -> Unit) {
    val wide = isWideWindow()
    val haptics = LocalHapticFeedback.current
    val pager = rememberPagerState(initialPage = state.mode.ordinal) { StandbyMode.entries.size }
    val currentMode by rememberUpdatedState(state.mode)

    // The pager reports only moves the user made; a move toward the ViewModel's mode is that mode arriving, not a choice.
    LaunchedEffect(pager) {
        snapshotFlow { pager.settledPage }.drop(1).collect { page ->
            haptics.performHapticFeedback(HapticFeedbackType.ContextClick)
            val mode = StandbyMode.entries[page]
            if (mode != currentMode) actions.onSelectMode(mode)
        }
    }
    LaunchedEffect(state.mode) {
        if (pager.settledPage != state.mode.ordinal) pager.animateScrollToPage(state.mode.ordinal)
    }

    var touches by remember { mutableIntStateOf(0) }
    var chromeVisible by remember { mutableStateOf(true) }
    LaunchedEffect(touches) {
        chromeVisible = true
        delay(CHROME_HIDE_MS)
        chromeVisible = false
    }
```

```kotlin
package com.saubh.deskbuddy.ui.standby.clock

import android.text.format.DateFormat
import androidx.compose.runtime.Composable
import androidx.compose.runtime.LaunchedEffect
import androidx.compose.runtime.State
import androidx.compose.runtime.mutableStateOf
import androidx.compose.runtime.remember
import androidx.compose.ui.platform.LocalContext
import androidx.compose.ui.platform.LocalDensity
import androidx.compose.ui.unit.IntOffset
import androidx.compose.ui.unit.dp
import kotlinx.coroutines.delay

/** Ticks on each second boundary, so every face changes digits on the same frame as the system clock. */
@Composable
fun rememberClockTime(): State<ClockTime> {
    val time = remember { mutableStateOf(ClockTime.now()) }
    LaunchedEffect(Unit) {
        while (true) {
            time.value = ClockTime.now()
            delay(1_000L - System.currentTimeMillis() % 1_000L)
        }
    }
    return time
}

@Composable
fun rememberIs24Hour(): Boolean {
    val context = LocalContext.current
    return remember(context) { DateFormat.is24HourFormat(context) }
}

/** Shifts the whole face a little every minute (±8 dp random walk) against OLED burn-in. */
@Composable
fun rememberBurnInOffset(): State<IntOffset> {
    val density = LocalDensity.current
    val offset = remember { mutableStateOf(IntOffset.Zero) }
    LaunchedEffect(density) {
        var dp = 0 to 0
        while (true) {
            delay(60_000L)
            dp = BurnInWalk.next(dp.first, dp.second)
            offset.value = with(density) { IntOffset(dp.first.dp.roundToPx(), dp.second.dp.roundToPx()) }
        }
    }
    return offset
}
```

```kotlin
@Composable
private fun FlipCard(value: String, reducedMotion: Boolean, modifier: Modifier) {
    var shown by remember { mutableStateOf(value) }
    var previous by remember { mutableStateOf(value) }
    val progress = remember { Animatable(1f) }
    LaunchedEffect(value) {
        if (value == shown) return@LaunchedEffect
        previous = shown
        shown = value
        if (reducedMotion) return@LaunchedEffect
        progress.snapTo(0f)
        progress.animateTo(1f, spring(dampingRatio = 0.8f, stiffness = Spring.StiffnessLow))
    }
    val density = LocalDensity.current.density
    Box(modifier) {
        // Static halves: new on top, old on the bottom until the lower flap lands on it.
        Half(shown, top = true)
        Half(previous, top = false)
        // Upper flap: the old value folding down (0 → -90°) during the first half of the motion.
        Half(previous, top = true, Modifier.graphicsLayer {
            val p = progress.value
            rotationX = -180f * p.coerceAtMost(0.5f)
            alpha = if (p < 0.5f) 1f else 0f
            transformOrigin = TransformOrigin(0.5f, 0.5f)
            cameraDistance = 12f * density
        }, shade = { progress.value })
        // Lower flap: the new value landing (90° → 0°, a little past with the spring).
        Half(shown, top = false, Modifier.graphicsLayer {
            val p = progress.value
            rotationX = 180f * (1f - p).coerceAtMost(0.5f)
            alpha = if (p >= 0.5f) 1f else 0f
            transformOrigin = TransformOrigin(0.5f, 0.5f)
            cameraDistance = 12f * density
        }, shade = { progress.value })
    }
}

@Composable
private fun Half(text: String, top: Boolean, modifier: Modifier = Modifier, shade: () -> Float = { 1f }) {
    val scheme = MaterialTheme.colorScheme
    BoxWithConstraints(
        modifier
            .fillMaxSize()
            .drawWithContent {
                val mid = size.height / 2f
                clipRect(top = if (top) 0f else mid, bottom = if (top) mid else size.height) {
                    this@drawWithContent.drawContent()
                    // Darkest mid-fold, as light leaves the flap.
                    drawRect(Color.Black.copy(alpha = 0.35f * sin(shade() * PI).toFloat()))
                }
                drawLine(Color.Black.copy(alpha = 0.6f), Offset(0f, mid), Offset(size.width, mid), strokeWidth = 2.dp.toPx())
            }
            .clip(RoundedCornerShape(20.dp))
            .background(scheme.surfaceContainerHigh),
        contentAlignment = Alignment.Center,
    ) {
        val fontSize = with(LocalDensity.current) { (maxHeight * 0.62f).toSp() }
        Text(text, fontSize = fontSize, fontWeight = FontWeight.Bold, color = scheme.onSurface)
    }
}
```

```kotlin
@Composable
private fun BubbleDigit(digit: Char, style: TextStyle, reducedMotion: Boolean) {
    AnimatedContent(
        targetState = digit,
        transitionSpec = {
            if (reducedMotion) {
                fadeIn(tween(200)) togetherWith fadeOut(tween(200))
            } else {
                (scaleIn(spring(dampingRatio = 0.6f, stiffness = Spring.StiffnessMediumLow), initialScale = 0f) + fadeIn()) togetherWith
                    (scaleOut(tween(180), targetScale = 0f) + fadeOut(tween(180))) using SizeTransform(clip = false)
            }
        },
        label = "bubble",
    ) { Text(it.toString(), style = style) }

    return rememberInfiniteTransition(label = "drift").animateFloat(
        initialValue = 0f,
        targetValue = 1f,
        animationSpec = infiniteRepeatable(tween(60_000, easing = LinearEasing), RepeatMode.Reverse),
        label = "drift",
    )
}
```

```kotlin
private val NEON_PINK = Color(0xFFFF3DCB)
private const val TAIL_DOTS = 14
private const val TAIL_DEGREES = 40f

/** Glowing analog hands; a seconds comet orbits the rim. Every animated read happens in the draw phase. */
@Composable
fun NeonOrbitFace(time: ClockTime, reducedMotion: Boolean, modifier: Modifier = Modifier) {
    val smooth = rememberSmoothSeconds(enabled = !reducedMotion && !LocalInspectionMode.current, fallback = time.second.toFloat())
    Canvas(modifier) {
        val radius = min(size.width, size.height) * 0.42f
        val c = center
        drawCircle(NEON_CYAN.copy(alpha = 0.12f), radius, c, style = Stroke(radius * 0.02f))
        repeat(12) { i ->
            val a = i * 30f
            drawLine(NEON_CYAN.copy(alpha = 0.35f), polar(c, radius * 0.88f, a), polar(c, radius * 0.96f, a), strokeWidth = radius * 0.015f, cap = StrokeCap.Round)
        }
        glowHand(c, ClockAngles.hour(time), radius * 0.5f, radius * 0.045f, NEON_PINK)
        glowHand(c, ClockAngles.minute(time), radius * 0.78f, radius * 0.03f, NEON_CYAN)
        val secondAngle = (if (reducedMotion) time.second.toFloat() else smooth.value) * 6f
        repeat(TAIL_DOTS) { i ->
            val f = i / (TAIL_DOTS - 1f)
            val angle = secondAngle - TAIL_DEGREES * f
            drawCircle(Color.White.copy(alpha = (1f - f) * 0.9f), radius * 0.03f * (1f - f * 0.6f), polar(c, radius, angle))
        }
        drawCircle(NEON_PINK, radius * 0.035f, c)
    }
}

private fun DrawScope.glowHand(c: Offset, degrees: Float, length: Float, width: Float, color: Color) {
    val tip = polar(c, length, degrees)
    drawLine(color.copy(alpha = 0.25f), c, tip, strokeWidth = width * 3.5f, cap = StrokeCap.Round)
    drawLine(color, c, tip, strokeWidth = width, cap = StrokeCap.Round)
}

/** Degrees clockwise from 12 o'clock → a point on the circle. */
private fun polar(c: Offset, r: Float, degrees: Float): Offset {
    val rad = Math.toRadians((degrees - 90f).toDouble())
    return Offset(c.x + r * cos(rad).toFloat(), c.y + r * sin(rad).toFloat())
}

/** Fractional seconds every frame (for a gliding comet); only the Canvas reads it, so nothing recomposes. */
@Composable
private fun rememberSmoothSeconds(enabled: Boolean, fallback: Float): State<Float> =
    produceState(fallback, enabled) {
        if (!enabled) return@produceState
        while (true) withFrameMillis { value = (System.currentTimeMillis() % 60_000L) / 1_000f }
    }
```

```kotlin
/** Retro LED dots; on change, columns switch to the new digits in a left-to-right wave. Date and battery underneath. */
@Composable
fun DotMatrixFace(time: ClockTime, is24h: Boolean, reducedMotion: Boolean, modifier: Modifier = Modifier) {
    val digits = time.digits(is24h)
    val text = "${digits.substring(0, 2)}:${digits.substring(2)}"

    var current by remember { mutableStateOf(previous) }
    val wave = remember { Animatable(1f) }
    LaunchedEffect(text) {
        val next = DotMatrixFont.columns(text)
        if (next == current) return@LaunchedEffect
        previous = current
        current = next
        if (reducedMotion) return@LaunchedEffect
        wave.snapTo(0f)
        wave.animateTo(1f, tween(next.size * WAVE_MS_PER_COLUMN, easing = LinearEasing))
    }
    val context = LocalContext.current
    val battery by produceState(batteryPercent(context)) {
        while (true) {
            delay(60_000L)
            value = batteryPercent(context)
        }
    }
    Column(modifier, horizontalAlignment = Alignment.CenterHorizontally, verticalArrangement = Arrangement.spacedBy(16.dp, Alignment.CenterVertically)) {
        Canvas(Modifier.fillMaxWidth(0.85f).aspectRatio(current.size / 7f)) {
            val cols = current.size
            val cell = min(size.width / cols, size.height / 7f)
            val dot = cell * 0.38f
            val switched = wave.value * cols
            for (c in 0 until cols) {
                val column = if (c < switched) current[c] else previous.getOrElse(c) { current[c] }
                for (r in 0 until 7) {
                    val center = Offset(c * cell + cell / 2, r * cell + cell / 2)
                    drawCircle(if (column[r]) LED_ON else LED_ON.copy(alpha = 0.08f), dot, center)
                }
            }
        }
        val date = remember(time.hour, time.minute) { DateFormat.getDateInstance(DateFormat.MEDIUM).format(Date()) }
        Text(date, style = MaterialTheme.typography.titleMedium, color = LED_ON.copy(alpha = 0.8f))
        if (battery >= 0) Text(stringResource(R.string.standby_battery, battery), style = MaterialTheme.typography.labelLarge, color = LED_ON.copy(alpha = 0.6f))
    }
}
```

## Task 20: Shutdown/restart countdown instead of a confirm dialog

**User request (2026-10-12):** tapping Shut down or Restart no longer asks in an alert dialog. Instead a 10-second countdown starts with a Cancel button. Cancelling sends nothing. When it reaches zero, the command is sent automatically. The user gets clear feedback throughout. This deliberately replaces the CLAUDE.md "confirmation dialog" rule for these two actions; the countdown serves the same purpose by making the action undoable. Lock stays instant.

**Design:**
- **The countdown lives in `PowerController`**, which is app-scoped. That way it survives rotation, navigation and entering or leaving standby, and it is unit-testable with virtual time.
- **The dialog is drawn once, at the app root** (`KonnektApp`), so it shows over Home and over standby alike.
- **If the PC disconnects mid-countdown**, the countdown ends with "Couldn't reach … Nothing was sent". It is never sent late.
- **Feedback:**
  - A draining ring with the seconds rolling down in the middle.
  - The title "Shutting down <PC>" and the hint "Save your work…".
  - A haptic tick each second, stronger for the last 3.
  - A large Cancel button.
  - When it ends, a result state (sent / cancelled / not reached) shows for 2 s, then the dialog closes on its own.

```kotlin
package com.saubh.deskbuddy.power

import com.saubh.deskbuddy.protocol.PowerAction
import com.saubh.deskbuddy.protocol.PowerCommand
import com.saubh.deskbuddy.session.MediaGateway
import kotlinx.coroutines.CoroutineScope
import kotlinx.coroutines.Job
import kotlinx.coroutines.delay
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.asStateFlow
import kotlinx.coroutines.launch

/**
 * Lock, restart and shut down the connected PC. Lock is instant; restart and shut down run a
 * [COUNTDOWN_SECONDS] countdown (app-scoped, so it survives navigation) that the user can cancel.
 */
class PowerController(private val gateway: MediaGateway, private val scope: CoroutineScope) {
    companion object {
        const val COUNTDOWN_SECONDS = 10
        const val RESULT_VISIBLE_MS = 2_000L
    }

    private val _countdown = MutableStateFlow<PowerCountdownState>(PowerCountdownState.Idle)
    val countdown: StateFlow<PowerCountdownState> = _countdown.asStateFlow()

    private var job: Job? = null

    init {
        // A countdown must never fire into a later connection, possibly to another PC.
        scope.launch { gateway.connected.collect { if (!it) finishEarly(PowerOutcome.NOT_CONNECTED) } }
    }

    fun send(action: PowerAction) {
        scope.launch { gateway.send(PowerCommand(action)) }
    }

    fun startCountdown(action: PowerAction, pcName: String) {
        if (_countdown.value is PowerCountdownState.Counting) return
        job?.cancel()
        job = scope.launch {
            for (left in COUNTDOWN_SECONDS downTo 1) {
                _countdown.value = PowerCountdownState.Counting(action, pcName, left)
                delay(1_000L)
            }
            val sent = gateway.send(PowerCommand(action))
            showResult(action, pcName, if (sent) PowerOutcome.SENT else PowerOutcome.NOT_CONNECTED)
        }
    }

    fun cancelCountdown() = finishEarly(PowerOutcome.CANCELLED)

    private fun finishEarly(outcome: PowerOutcome) {
        val counting = _countdown.value as? PowerCountdownState.Counting ?: return
        job?.cancel()
        job = scope.launch { showResult(counting.action, counting.pcName, outcome) }
    }

    private suspend fun showResult(action: PowerAction, pcName: String, outcome: PowerOutcome) {
        _countdown.value = PowerCountdownState.Finished(action, pcName, outcome)
        delay(RESULT_VISIBLE_MS)
        _countdown.value = PowerCountdownState.Idle
    }
}
```

```kotlin
@Composable
private fun Counting(s: PowerCountdownState.Counting, onCancel: () -> Unit) {
    val haptics = LocalHapticFeedback.current
    val total = PowerController.COUNTDOWN_SECONDS.toFloat()
    // Starts from the current second, so a rotation mid-countdown resumes the ring where it was.
    val ring = remember { Animatable(s.secondsLeft / total) }
    LaunchedEffect(s.secondsLeft) {
        haptics.performHapticFeedback(if (s.secondsLeft <= 3) HapticFeedbackType.LongPress else HapticFeedbackType.SegmentTick)
        ring.animateTo((s.secondsLeft - 1) / total, tween(1_000, easing = LinearEasing))
    }
    val restart = s.action == PowerAction.RESTART

        CircularProgressIndicator(
            progress = { ring.value },
            modifier = Modifier.size(160.dp),

            trackColor = MaterialTheme.colorScheme.surfaceContainerHighest,
            strokeWidth = 10.dp,

            targetState = s.secondsLeft,
```
